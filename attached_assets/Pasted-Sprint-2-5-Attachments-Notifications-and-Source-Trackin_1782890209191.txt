Sprint 2.5 — Attachments, Notifications, and Source Tracking
Objective
Allow accountants to attach supporting documents to journal entries, track the originating source module and reference, and notify stakeholders on every workflow event. Auditors get documentation linked directly to each entry; source tracking provides a navigable link back to the originating transaction in any other ERP module.

Acceptance Criteria
#	Criterion
1	Up to 10 attachments uploadable per entry; validated MIME allowlist + 20 MB size limit
2	Invalid MIME types and oversized files rejected at API level (400)
3	Attachments downloadable via signed URL with 15-minute TTL
4	Soft-deleted attachments absent from subsequent list responses
5	isPrimary flag — at most one per entry; setting a new primary auto-clears the previous
6	Source type and reference visible on detail page
7	If sourceModuleUrl is set, a clickable relative link is shown
8	Notifications emitted on: submitted, approved, rejected, posted, locked, voided, reversed
9	Unread notifications retrievable; marking one or all as read works
10	All Sprint 2.1–2.4 acceptance criteria continue to pass
11	TypeScript zero errors; build succeeds; all tests pass
